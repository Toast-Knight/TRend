# Security Policy

## Supported Versions

Security fixes are applied to the latest revision on the default branch. No
older release line is currently maintained.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting from the repository's **Security**
tab. Do not open a public issue for an unpatched vulnerability or include
exploit details in public discussions.

Include the affected component, platform, reproduction steps, expected impact,
and any proposed mitigation. You should receive an initial response through
GitHub within seven days. Public disclosure should wait until a fix or agreed
mitigation is available.

Media decoders process untrusted structured input. Reports involving malformed
files, memory limits, integer overflow, unsafe FFI boundaries, or native codec
loading are especially relevant.
